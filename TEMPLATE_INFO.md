# Информация о шаблоне

**Номер проекта:** 24

**Название папки:** `code-collaboration-lab`

**Шаблон проекта:** `Учёт проектов`

**Ссылка на GitHub:** `https://github.com/pipelineOfProjects1t/code-collaboration-lab`

**Файл данных:** `projects.json`

## Что лежит в папке

- `main.py` — готовое консольное приложение на Python.
- `projects.json` — JSON-файл для хранения данных.
- `README.md` — описание проекта, запуск, ссылка на GitHub и порядок сдачи.
- `GIT_STEPS.md` — пошаговые команды Git и GitHub.
- `ISSUE_EXAMPLE.md` — пример задачи в GitHub Issues.
- `PULL_REQUEST_DESCRIPTION.md` — пример описания Pull Request.
- `tests/` — модульные тесты.

## Какой это шаблон

Это шаблон проекта «Учёт проектов». Его можно использовать как отдельный репозиторий `code-collaboration-lab` для практического кейса по совместной разработке с Git и GitHub.
