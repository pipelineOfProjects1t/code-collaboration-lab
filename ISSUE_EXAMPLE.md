# Issue example

## Заголовок

Запретить пустое название проекта

## Описание

В проекте «Учёт проектов» нужно добавить проверку пользовательского ввода и защиту от некорректных данных.
Это позволит сделать приложение надежнее и показать работу с GitHub Issues.

## Как закрыть Issue коммитом

```bash
git commit -m "Запретить пустое название проекта. Closes #1"
```

После пуша ветки на GitHub задача закроется автоматически, если номер Issue действительно равен `#1`.
